# Native Android Weather Forecast Application

A native Android application developed to fetch, process, and display real-time weather information by integrating dynamic REST API payloads from OpenWeatherMap.

## Tech Stack & Features
* **Language:** Java
* **Platform:** Android SDK
* **Architecture:** Asynchronous network requests to handle live REST API data parsing and render meteorological data dynamically.
* **Core Functionality:** Location-based weather retrieval, temperature conversion, and responsive UI layout designed for mobile devices.

---

## Opis projekta
Maternja Android aplikacija za vremensku prognozu kreirana u Javi. Aplikacija vrši asinehrone mrežne zahteve ka OpenWeatherMap API-ju, parsira JSON odgovore u realnom vremenu i prikazuje trenutne vremenske uslove i prognozu kroz prilagođeni mobilni interfejs.
